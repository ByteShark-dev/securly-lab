Fase 5A — URL rewriting sin red externa

Esta fase muestra cómo una capa tipo Scramjet puede separar la URL que una página cree estar usando de la URL que termina viendo el navegador. Todo se hace localmente: demo.invalid es un dominio reservado de ejemplo y ninguna de las URLs transformadas se ejecuta contra ese destino.

← Volver a Fase 4F Laboratorio principal
Este laboratorio NO es un proxy. No recupera contenido remoto, no abre sockets hacia los destinos del HTML y no permite elegir destinos arbitrarios. Solo transforma strings y simula la decisión que tomaría el navegador.

Por qué fetch() es diferente

El HTML contiene: fetch("/api/profile") Un parser de atributos no ve esa URL porque está dentro de JavaScript. En esta fase la simularemos con una función labFetch() que RESUELVE y REESCRIBE la URL, pero deliberadamente NO ejecuta fetch() real.
