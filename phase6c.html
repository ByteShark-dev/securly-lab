Fase 6C — Runtime Leak Audit

Esta fase busca huecos de cobertura en un runtime virtual. Si una operación que puede contener una URL no tiene handler, marcamos que la URL lógica podría llegar a la API nativa. No ejecutamos la API: el “leak” es una predicción local del modelo.
